- 手集金とStripe入金を別々に集計できるようにしました。
- 年度別集計として以下を表示する構成にしました。
  - 請求額
  - 入金合計
  - 手集金
  - Stripe入金
  - 未入金額
  - 未納/一部入金件数
- ボタンの重なり、位置ずれを調整しました。

### 4. システム利用料管理の追加

- el-town側のシステム管理画面で、システム利用料の単価設定を行えるようにしました。
- 設定項目:
  - 接続数1件あたり単価
  - 無料プッシュ件数
  - プッシュ件数超過単価
  - 消費税率
- 月ごとの利用料請求を扱えるようにしました。
- 毎月1日付で、前月利用分の請求を確定する構成にしました。
- 町内会・自治会ごとの月次請求を保存し、重複する月次請求を月ごとに管理できるようにしました。
- 請求書PDF、領収書PDFを出力できる画面を追加しました。
- Stripeでシステム利用料を支払えるAPIを追加しました。
- Stripe入金後、Webhookで入金済み、入金額、領収書番号、Stripe決済IDを保存する処理を追加しました。
- 入金済みの月次請求は再確定しても上書きしないようにしました。

### 5. 役員管理の追加

- 役員候補者に送る招待URLを作成できるようにしました。
- 招待された役員候補者は、URLからログイン認証し、管理者として加われる構成にしました。
- 役員を最大20名までに制限しました。
- 役員を退任できるようにし、誤操作時に復活できる設計を追加しました。
- 退任済みのメールアドレスは、他の町内会・自治会でも利用できる設計にしました。
- 招待中の誤登録については、退任ではなく削除できるようにしました。
- 本日作成されたテスト招待レコードは削除済みです。
  - 対象: `id=33 / arai@qoin.co.jp / status=pending`

### 6. Stripe連携方針の変更

- 町内会・自治会向けのStripe連携は、本番モードから登録する仕様に変更しました。
- 町内会・自治会にテストモード登録や本番切替操作は求めない方針にしました。
- 契約主体は、各町内会・自治会とStripeとしました。
- el-townは、Stripe Connectを使った登録導線、会費請求、Webhook入金反映、領収書出力の仕組みを標準機能として提供する整理にしました。
- el-town運営・開発環境では、内部検証用にStripeテストモードを利用する方針を残しました。
- 管理画面のStripe連携を以下の表示に変更しました。
  - 本番Stripe登録を開始
  - 本番登録を再開・確認
  - 本番決済受付中
  - Stripe審査中
  - 本番登録の完了待ち
- 本番環境ではStripe本番キー以外で登録・決済できないようにAPI側でガードを追加しました。
- 会費のStripe請求・会員側オンライン支払いは、本番Stripe連携が有効になってから利用できるようにしました。
- Stripeマニュアルから「テスト接続から本番登録まで」の流れを削除し、「本番Stripe登録から会費請求まで」に変更しました。
